## My process

### Built with

- Semantic HTML5 markup
- CSS custom properties
- Mobile-first workflow
- Media queries
- CSS table styling
- Google Fonts

### What I learned

This project helped me practice:

- building a page with semantic HTML sections
- using a wrapper to control spacing without pushing the image inward
- styling a table with borders and removing the last divider line
- working with a mobile-first layout and adjusting styles for desktop
- choosing meaningful class names for different parts of the page

### Continued development

In future projects, I want to keep improving:

- responsive spacing decisions
- table styling
- layout planning before writing CSS
- making breakpoint choices based on the design instead of guessing

### AI Collaboration

I used AI as a learning helper while building this project.

- It helped me break the challenge into smaller steps.
- It helped me check my HTML structure and CSS choices.
- It helped me understand where to place spacing, width, and responsive styles.
- It did not write the project for me, but it helped me think through the layout more clearly.
